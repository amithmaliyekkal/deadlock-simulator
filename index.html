💀

Deadlock

A set of processes where every member waits for a resource held by another member. Requires: mutual exclusion, hold & wait, no preemption, circular wait.

📊

Allocation Matrix

How many instances of each resource type each process currently holds.

📋

Request Matrix

How many additional instances each process needs right now.

📦

Available Vector

Free instances of each resource type not allocated to any process.

🔍

Detection Algorithm

  1. Set Work = Available.
  2. Mark process i Finished if its Allocation is all zero; else Unfinished.
  3. Find an unfinished process whose Request ≤ Work.
  4. Mark it finished; add its Allocation to Work.
  5. Repeat until no more can finish.
  6. Any still-unfinished process is deadlocked.
🛠️

Recovery

Abort a deadlocked process, reclaim its resources, and rerun detection. Real systems may also rollback or use priority preemption.
